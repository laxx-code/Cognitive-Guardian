# Cognitive Guardian

On-device anti-doomscroll guardian prototype.

- `android/` — Kotlin: AccessibilityService, overlay, Gemini Nano bridge
- `ios/` — Swift: in-app demo feed, overlay, Foundation Models bridge
- `src/` — Shared React Native core: buffer, prompt, screens, dev-menu mock injector
- `assets/mockFeeds/` — Synthetic test posts (neutral / rage-bait / toxic) used by the dev-menu injector, your live-demo safety net
- `docs/` — Implementation roadmap

See `docs/implementation_roadmap.md` for the 5-day plan and task split.
